    A.Divisible Permutation

    题目描述

    给你一个整数 $n$，要构造一个长度为 $n$ 的排列 $p$（包含 $1\sim n$ 且互不相同），满足对所有 $1\le i\le n-1$：

    多组测试，输出任意一种满足条件的排列即可。

    数据范围

    第一行一个$T(1 \leq T \leq 10^4)$，对于每组数据：

    • 第一行一个$n (1 \leq n \leq 2 \times 10^5)$

    题解

    思考一种构造：最后一位取1，那么倒数第二位就可以是n，倒数第二位是n，倒数第三位就可以是2…这样就可以是一个干净的构造

    证明：

    注意：|a - b|被i整除等价于a ≡ b (mod i)

    为什么一定满足条件？

    设a的相邻差$\Delta_k = a_{k+1} - a_k,(1 \leq k \leq n - 1)$，验证它对不对等价于验证$(n-k) \;|\; |a_{k} - a_{k+1}|$

    而a的形式：

    • 若k=2t-1，则$a_k = t$，$a_{k+1}=n - t + 1$，$|\Delta_k| = |n-t+1-t|=n-2t+1=n-k$
    • 若k=2t，则$a_k = n-t+1,a_{k+1}=t + 1$，$|\Delta_k| = |(t + 1) - (n-t+1)|=n-2t=n-k$

    也就是说对于每个k，都有$|a_{k+1}-a_k| = n - k$

    B.Seats

    题目描述

    有一排 n 个座位，用一个二进制串 s 表示当前坐人情况：

    • s[i]=1 表示第 i 个座位已有学生坐下
    • s[i]=0 表示空位
      并保证当前 没有相邻的两个 1（即没人坐在相邻座位）。

    你可以继续往空位上安排学生，但必须始终满足“任意两个学生不能相邻”。
    Cordell 想一直加人，直到变成 再也无法加任何学生（即当前坐法已经“放满到极限”，任何空位都因为相邻有人而不能坐）。

    要求：在达到这种“无法再加人”的状态时，总坐下的学生人数最少是多少？

    数据范围

    第一行一个$T(1 \leq T \leq 10^4)$，对于每组数据：

    • 第一行一个$n (1 \leq n \leq 2 \times 10^5)$
    • 第二行一个长度为n的字符串s
    • $\sum n \leq 2 \times 10^5$

    题解

    最终状态满足：

    • 不相邻的1
    • 没办法再加：对任意一个0位置，左右至少有一个是1

    所以问题变成：在包含所有初始1的前提下，构造一个不相邻且能覆盖所有0（每个0都贴着1）的最终串，并使1的总数最小.

    用三个状态表示第i个位置的情况：

    • 0：i位置选为1
    • 1：i位置为0，但左边有人
    • 2：i位置为0，还没被覆盖，只能指望i+1选1来覆盖它

    转移只依赖前一位状态，满足：

    • 若状态是2，下一位必须选1来补覆盖
    • 若上一位选了1，下一位不能选1
    • 若s[i] = 1，则该位必须选1

    答案是min(dp0,dp1)

    复杂度：$O(n)$

    C.Restricted Sorting

    题目描述

    给定长度为 $n$ 的数组 $a$。对一个整数 $k$，如果我们可以做任意次操作把 $a$ 变成非降序，则称 $k$ 是 piggy：

    • 任选两个下标 i，若 $|a_i-a_j|\ge k$，则可以交换 $a_i,a_j$。

    对每个测试用例，求最大的 piggy 整数 $k$。如果不存在最大值（也就是对任意大 $k$ 都能排序），输出 $-1$。

    数据范围

    第一行一个$T(1 \leq T \leq 10^4)$，对于每组数据：

    • 第一行一个$n (1 \leq n \leq 2 \times 10^5)$
    • 第二行一个长度为n的数组a
    • $\sum n \leq 2 \times 10^5$

    题解

    什么时候会输出-1呢？

    • 本身就是非降序，对任意大的k都成立，所以没有最大值，即-1

    对于固定的一个k，哪些数动不了?

    设mn = min(a), mx = max(a)，对于每个值x：

    • 如果同时满足：x - mn < k 且 mx - x < k，那么距离最小值和距离最大值都不到k，则无法与任意值交换
    • 否则，x至少能和mn/mx交换，当$mx - mn \geq k$时，mn和mx也能交换，所以这些能交换的值一定可以通过一系列合理的交换实现任意重排

    能否交换的k单调，k越大能交换的越少，越难排序，因此在[0, mx - mn]上二分可行k

    复杂度：O(nlogn)

    D.Shortest Statement Ever

    题目描述

    给两个非负整数 $x,y$。你要找两个非负整数 $p,q$，满足 按位与 $p \& q = 0$（即同一二进制位不能同时为 1），并使

    最小。若最优解不唯一，输出任意一组即可。

    数据范围

    第一行一个$T(\leq 10^4)$

    对于每组数据，两个非负整数$x,y (0 \leq x,y \leq 2^{30})$

    题解

    约束$p \& q = 0$是逐位独立的，所以只能是(1,0)或(0,1)，不能选(1,1)，所以要按位从低到高做dp

    目标函数为什么难？绝对值

    需要最小化$|x-p|+|y-q|$，绝对值导致方向不确定，比如$|x-p|$可能是x-p也可能是p-x，所以要拆成四种情况：

    • x-p,y-q
    • x-p,q-y
    • p-x,y-q
    • p-x,q-y

    每种情况里，目标变成两个非负差的和，对四种情况分别求最小，再整体求最小即可。

    固定方向后，差值可以用二进制减法+借位逐位计算，以x-p为例，在第i位：

    • 已知$x_i \in \{0,1\}$
    • 我们要选$p_i \in \{0,1\}$
    • 还要考虑从低位传来的结尾$b \in \{0,1\}$

    这一位的结果位是：$r_i = (x_i - p_i - b) \; mod \; 2$

    下一位的结尾是：$b’ = [x_i - p_i - b < 0]$

    而最终：$x - p = \sum_{i}r_i 2^i$

    可以在dp里逐位累加贡献，这一位贡献就是$r_i \times 2^i$，对于y-q同理

    设计dp：因为要同时算两个差，所以状态是：

    • bx：当前位处理前，计算x-p这个减法从低位传来的借位(0/1)
    • by：计算y-q这条减法的借位(0/1)

    因此状态数是$2 \times 2 = 4$

    用dp处理bit从0到30（足够覆盖答案$< 2^{31}$）：$dp[i][bx][by] = 处理完低i位的最小代价$

    转移：枚举当前位$(p_i,q_i)$的三种合法选择，然后用减法规则算出：

    • 这一位差值结果位$r_x,r_y$
    • 下一位借位$bx’,by’$

    代价增加：$(r_x + r_y) \times 2^i$

    边界条件：为什么结束必须借位为0

    比如算x-p：

    • 如果最终最高位处理完后借位还为1，说明整体不够减，即x < p
    • 那么这种情况不成立，这条路径无效

    所以每种方向dp的合法答案必须满足最终(bx,by)=(0,0)

    这就自动保证了：

    • 若用x-p形式，那最终一定$x \geq p$
    • 若用p-x形式，那最终一定$x \leq p$

    绝对值的方向就被借位是否为0约束了

    F.Cool Problem

    题目描述

    给定整数常量 $x,y$。对任意二进制串 $r$（长度 $n$），定义序列 $c_0=0$，并对 $1\le i\le n$：

    • 若 $r_i=0$，则 $c_i=c_{i-1}+x$
    • 若 $r_i=1$，则 $c_i=y-c_{i-1}$

    定义 $f(r)=\sum_{i=1}^n c_i$。

    现在给你一个长度为 $n$ 的不完整串 $s\in\{0,1,?\}^n$。把每个 ? 替换成 0/1 得到一个完整串 $r$。若某个整数 $k$ 能作为某种补全后的 $f(r)$，则称 $k$ 是 cool。

    要求：对每个测试用例，输出 所有 cool 整数的去重后求和（每个值只算一次），对 $998244353$ 取模。

    数据范围

    第一行一个$T(\leq 10^4)$，对于每组数据：

    • 第一行$n,x,y(1 \leq n \leq 10^5,1 \leq x,y \leq 10^6)$
    • 第二行包含一个长度为n的字符串s
    • $\sum n \leq 10^5$
