A.Table with Numbers

题目描述

给定一个\(h \times l\)的表格，初始全为0，给定数组\(a_1, \dots, a_n\)，你可以选出\(2k \leq n\)个数，把它们分成\(k\)对\((x,y)\)。对每一对\((x,y)\)，如果表格中存在第x行第y列（即\(1 \leq x \leq h \; 且 \; 1 \leq y \leq l\)），则该格子加一，否则这对不产生作用，问表格中元素的最大值。

数据范围

输入\(T(1 \leq T \leq 500)\)组数据，对于每组数据：

  • 第一行\(n, h, l(2 \leq n \leq 100, 1 \leq h,l \leq 1000)\)
  • 第二行\(a_1 \dots a_n(1 \leq a_i \leq 1000)\)

题解

把数组元素是否能当行/列分类：

  • 两个都可以：\(\leq min(h, l)\)
  • 只能当行：\(\leq h\)但\(> l\) （只在\(l < h\)的时候出现）
  • 只能当列：\(\leq l\)但\(>h\) （只在\(h < l\)的时候出现）

如果想做出\(k\)个有效对：

  • 需要\(k\)个行元素：两个都可以+只能当行
  • 需要\(k\)个列元素：两个都可以+只能当列
  • 两个都可以的元素要在当行/列分配，不能重复用

只要检查\(k\)是否可行：

  • 行还缺：\(max(0, k-onlyRow)\)
  • 列还缺：\(max(0, k - onlyCol)\)
  • 这两部分都要从两个都可以的元素拿，要求：\(max(0,k-onlyRow) + max(0,k-onlyCol) \leq both\)

复杂度每组\(O(n)\)

B.The Curse of the Frog

题目描述

起点在0，共有\(n\)种跳法：

  • 用第\(i\)种跳法依次：如果当前在\(k\)，则可以落在任意点\([k,k+a_i]\)
  • 但第\(i\)种跳法每到第\(b_i,2b_i,3b_i,\dots\)，使用前会先回退\(c_i\)，即从\(k\)先变成\(k-c_i\)，再落在\([k-c_i,k-c_i+a_i]\)

目标是到达点\(x\)，输出最少回退次数，如果到不了输出-1.

数据范围

输入\(T(1 \leq T \leq 10000)\)组数据，对于每组数据：

  • 第一行\(n, x(1 \leq n \leq 10^5, 1 \leq x \leq 10^{18})\)
  • 之后的n行，每行\(a_i,b_i,c_i(1 \leq a_i,b_i,c_i \leq 10^6)\)
  • \(\sum n \leq 10^5\)

题解

我们关心，给定回退次数\(R\)，最远能到多远？因为每次落点是一个连续区间内任意一个点，只要最远能到\(\geq x\)，就能通过最后几步少跳一点精确落在\(x\)

  1. 0次回退能白嫖到多远？

对第\(i\)种跳法，如果不想触发回退，就是最多用到第\(b_i - 1\)次，所以第\(i\)种能免费提供的最大前进距离是\(a_i \times (b_i - 1)\)

因此，总最远距离\(Dis = \sum_{i=1}^n a_i \times (b_i - 1)\)，若\(x \leq Dis\)，则答案就是0.

  1. 一次回退的价值？

如果决定让第\(i\)种跳法触发一次回退，那么最优的方式是：

  • 先用它若干次到临界，每触发1次回退，总能安排出一整段“包含恰好1次回退”的使用块
  • 这段块里共有\(b_i\)次使用，其中\(b_i - 1\)次正常，每次最多\(+ a_i\)
  • 那一次回退使用：先\(- c_i\)，再最多加\(a_i\)，净增\(a_i - c_i\)

所以每多花一次回退，第\(i\)种跳法能带来的额外最大净前进是：\(W_i = a_i b_i - c_i\)

如果我们有\(R\)次的回退预算，为了走的最远，显然把每一次回退用到\(W_i\)最大的那种跳法上最划算

令\(W = max W_i\)，则：

  • 若\(W \leq 0\)，说明任何回退都不能让最远位置超过\(Dis\)，所以\(x > Dis\)时无解
  • 否则最远能够跳到\(Dis + R \times W\)
  1. 最少回退次数

要到达\(x\)，最少\(R\)满足：\(Dis + R \times W \geq x\),因此\(R = \lceil \frac{x-Dis}{W} \rceil\)

每组数据\(O(n)\)

C1.XOR Convenience (Easy Version)

题目描述

给定一个整数\(n\)，构造一个1到\(n\)的排列\(p\)，要求：

  • 对于每个\(i(2 \leq i \leq n - 1)\)，存在某个位置\(j \geq i\)，使得\(p_i = p_j \oplus i\)，\(\oplus\)是异或

题目保证一定存在解，输出任意一个即可。

数据范围

输入\(T(1 \leq T \leq 10000)\)组数据，对于每组数据：

  • 输入一个数\(n(3 \leq n \leq 2 \times 10^5)\)
  • \(\sum n \leq 2 \times 10^5\)

题解

直接让所有\(i\)取同一个\(j = n\)。

令：

  • \(p_n = 1\)
  • 对所有\(i = 2,3,\dots,n-1\)，令\(p_i = 1 \oplus i\)，也就是把i的最低位反转，偶数变成\(i+1\)，奇数变成\(i-1\)
  • 剩下没用到的那个数填到\(p_1\)

为什么满足条件？

对任意\(i \in [2,n - 1]\)，取\(j = n\)，则\(p_j \oplus i = p_n \oplus i = 1 \oplus i = p_i\)直接成立

为什么是排列？

  • 映射\(i \rightarrow i \oplus 1\)在不同\(i\)上结果不同，所以\(p_2,\dots,p_{n-1}\)互不相同
  • 再加上\(p_n=1\)，总共用了\(n-1\)个不同数
  • 最后一个数填到\(p_1\)

结论：若\(n\)是偶数，剩下\(n\)，若是奇数，剩下的是\(n-1\)

每组数据\(O(n)\)

C2.XOR-convenience (Hard Version)

题目描述

给定一个整数\(n\)，构造一个1到\(n\)的排列\(p\)，要求：

  • 对于每个\(i(1 \leq i \leq n - 1)\)，存在某个位置\(j \geq i\)，使得\(p_i = p_j \oplus i\)，\(\oplus\)是异或

与C1不一样的是\(i\)的取值变成最小是1

数据范围

输入\(T(1 \leq T \leq 10000)\)组数据，对于每组数据：

  • 输入一个数\(n(3 \leq n \leq 2 \times 10^5)\)
  • \(\sum n \leq 2 \times 10^5\)

题解

  1. 新增的\(i=1\)会多出什么要求？

对\(i=1\)，条件变成：\(\exist j \in [1, n]\)，使得\(p_1 = p_j \oplus 1\)，等价于\(p_j = p_1 \oplus 1\)，所以必须满足\(p_1 \oplus 1 \in [1,n]\)

特别的：

  • \(p_1 \neq 1(1 \oplus 1 = 0 \notin [1,n])\)
  • 如果\(p_1 =n\)且\(n\)是偶数，则\(n \oplus 1 = n + 1\)越界，不行
  1. 哪些\(n\)会无解？

当\(n=2^k\)的时候无解

证明：

  • 数字n必须出现在某个位置k
  • 若\(k \leq n - 1\)，则对\(i=k\)必须存在\(j \geq k\)使得\(p_k = p_j \oplus k\)，即\(p_j = n \oplus k\)
  • 但当\(n = 2^k\)时，任意\(1 \leq k \leq n - 1\)都有\(n \oplus k = n + k > n\)，不合理
  • 因此只能\(p_n = n\)，再看\(i = n-1\)，唯一可选的就是\(j = n\)，于是\(p_{n-1}=p_n\oplus(n-1)=n\oplus(n-1)=2n-1 > n\)也矛盾

所以\(n=2^k\)一定无解

  1. 构造(当\(n \neq 2^k\))

先做一个几乎全对的场景：

  • 令\(p_n = 1\)

  • 对\(i = 2,\dots,n-1\)，令\(p_i = i \oplus 1\)，则对\(i \geq 2\)，直接取\(j = n\)满足\(p_i = 1 \oplus i\)，剩下只需要处理\(i=1\)

    1. n为奇数

    此时上面的构造用到了所有数，缺的唯一就是\(n-1\)，令\(p_1 = n-1\)

    1. n为偶数

    此时缺的数是n，如果直接让\(p_1 = n\)，则\(n \oplus 1 > n\)，不行，考虑一个调整

    令\(k = lowbit(n)\)，然后交换\(p_1\)和\(p_k\)

    • \(i=1\)会变成\(p_1 = k \oplus 1\)，其异或1得到k，一定在排列中
    • \(i=k\)位置放了\(n\)，需要的伙伴是\(n \oplus k = n-k\)，它在构造中出现在位置\((n-k) \oplus 1 = (n-k) + 1 \geq k\)，满足\(j \geq i\)
    • 其余\(i \geq 2,i\neq k\)，仍用\(j = n\)解决

D1.Little String (Easy Version) / D2.Little String (Hard Version)

题目描述

对于一个长度为n的串\(w_1,w_2,\dots,w_n\)（只含0/1），定义\(f(w)\)为满足下列条件的排列\(p\)（排列的是\([0,1,\dots,n-1]\)）:

对每个\(i=1\dots n\)：

  • 若\(w_i=1\)，则存在某个子数组\(p_l \dots p_r\)，使得\(mex(p_l \dots p_r) = i\)
  • 若\(w_i = 0\)，则不存在任何子数组的mex等于i

现给定串s（含0/1/?），可把每个?替换成0/1得到某个w。给定整数c，要在所有可行w中找最小的\(f(w)\)，要求\(f(w)\)不被c整除；若不存在输出-1，答案对\(10^9+7\)取模输出

数据范围

输入\(T(1 \leq T \leq 10000)\)组数据，对于每组数据：

  • 第一行输入\(n,c (3 \leq n \leq 2 \times 10^5, 1 \leq c \leq 10^9)\)
  • 第二行一个字符串s
  • \(\sum n \leq 2 \times 10^5\)

题解

对任意排列p，令pos(x)表示数x在p中的位置

子数组mex=i(\(1 \leq i \leq n - 1\))存在的充要条件：

设 \[ L = min_{0 \leq x \leq i - 1} pos(x), R = max_{0 \leq x \leq i - 1} pos(x). \] 则存在子数组mex为i当且仅当\(pos(i) \notin [L,R]\)

原因？

任何包含\(0,1,\dots,i-1\)的子数组必须覆盖区间\([L,R]\)，若\(i\)落在区间\([L,R]\)内，则无法避开i，mex不可能是i，反之只要取\([L,R]\)即可

于是\(w_i = 1\)等价于\(pos(i)\)是当前\(\{0 \dots i\}\)的位置最左/右新纪录，\(w_i = 0\)等价于落在中间

进一步可以得到计数公式：

  • 必然有\(w_1 = 1\)两点必在端点、\(w_n = 1\)整个数组mex为n
  • 若\(w_1\)或\(w_n\)为0，则\(f(w) = 0\)
  • 否则\(f(w) = \prod_{i=1}^{n-1} \begin{cases} 2, w_i = 1 \\ i - 1, w_i = 0 \end{cases}\)
    • 按i=1,2,…依次把数i插入当前已出现数字在排列中的相对顺序
      • 若\(w_i = 1\)，只能插入到两端
      • 若\(w_i = 0\)，只能插入到中间
    • 因此\(f(w)\)按位独立相乘，就让含?的最小化变成贪心

如何在?中取最小且保证不被c整除？

先构造最小乘积的w：

  • \(w_1 = w_n = 1\)(若\(s_1\)或\(s_n\)固定为0直接无解)
  • 对\(2 \leq i \leq n - 1\)
    • 若\(s_i = 0\)：只能取0，因子是\(i-1\)
    • 若\(s_i = 1\)：只能取1，因子是2
    • 若\(s_i = ?\)：选更小的
      • \(i=2\)，选0
      • \(i \geq 3\)，选1

得到最小值\(F_{min}\)

如果最小值不整除，答案就是这个，否则降低这种整除性的可能就是降低2的指数（把某些原本选1的位置从因子2改成奇数i-1，会让2的幂次减少1）。

为什么？

\(c = m \times 2^e\)，m为奇数。因此被c整除等价于同时满足：

  • 结果含有至少e个2因子
  • 结果含有m的所有奇质因子

做一次替换把2换成i-1，会发生：

  1. i是奇数

此时i-1是偶数，原来因子是2换成i-1（至少也含有一个2，也可能含有更多的2），所以2的指数不会减少，通常还会增加，同时可能引入更多奇素因子，因此这种替换只会让整除性更强。

  1. i是偶数

此时i-1是奇数，原来因子是2，换成奇数i-1，所以2的指数减一，虽然可能引入奇数，但是无伤大雅

这只可能发生在：

  • i为偶数且\(s_i = ?\)（此时可把2改成奇数i-1）

设c中2的指数为\(e = v_2(c)\)，而当前\(F_{min}\)中2的指数为\(t = v_2(F_{min})\)。要想最终不被c整除，足够让2的指数小于e，至少需要\(k = t - e + 1\)次2变成奇数的这种替换。每次替换会让总乘积乘上\(\frac{i-1}{2}\)，要使结果尽量小，就选i最小的k个偶数位置。

如果c为奇数且\(F_{min}\)已经被c整除，无论怎么替换都会引入更多的奇素因子，无法破坏整除，输出-1

奇数 \(c\) 不关心你有多少个 2，因为 2 不是它的质因子；你拿掉一些 2，不会破坏 “含有 \(c\) 的所有奇质因子” 这个事实。因此无论怎么换，f(w)仍然被c整除。

时间复杂度：O(\(\sum n\))

E.Majority Wins?

题目描述

给定一个长度为 \(n\) 的二进制字符串 \(s\)（只含 0 和 1）。

你可以对当前字符串 \(g\)（长度为 \(k\)）反复进行如下操作：

  1. 任选一段连续子串 \(g_l g_{l+1}\dots g_r\)（\(1 \le l \le r \le k\)）。
  2. 统计这段子串里 0 的数量和 1 的数量。
  3. 用一个字符替换这整段子串：
    • 如果该子串里 1 的数量 不少于 0 的数量（即 1 是“多数或平局”），你可以把它替换成 1；
    • 如果该子串里 0 的数量 不少于 1 的数量（即 0 是“多数或平局”），你可以把它替换成 0。 （当 0 和 1 数量相等时，两种替换都允许。）

这次操作的代价为该子串长度 \((r-l+1)\)。

目标：用若干次（也可以 0 次）操作把整个字符串 \(s\) 变成只剩一个字符的字符串 "1"，并使总代价最小。 如果无论如何都无法变成 "1"，输出 \(-1\)。

输入包含多组测试：第一行是 \(t\)，每组给出 \(n\) 和字符串 \(s\)。输出每组的最小总代价或 \(-1\)。

数据范围

第一行\(T(1 \leq T \leq 10^4)\)，对于每组数据：

  • 第一行\(n(1 \leq n \leq 5 \times 10^5)\)
  • 第二行一个长度为n的字符串s
  • \(\sum n \leq 5 \times 10^5\)

题解

把每次替换成1个字符看成合并，设总共做了k次操作，则无论怎么合并，每次合并多长，总成本恒有：\(cost = \sum (每次合并段长) = n + k - 1\)

总共减少了n-1，设\(L_j\)表示第j次操作选的子串长度，则\(\sum_{j=1}^k(L_j - 1) = n - 1\)，所以\(\sum_{j = 1}^k L_j = n + k - 1\)

因此最小化cost等价于最小化操作次数k。

把字符’1’变成1，字符’0’变成-1

  • 全串和：\(D = \sum a_i = (\#1) - (\#0) = 2 \times \#1 - n\)
  • 任意子串和\(S\)

一次操作把某子串替换成：

  • 1需要该子串1不少于0，即\(S \geq 0\)
  • 0，即\(S \leq 0\)

并且全串和D会变化为：

  • 1：\(D' = D + (1 - S)\)
  • 0:\(D' = D+ (-1-S)\)

判定最少操作次数：

  • 无解：没有’1’，输出-1
  • 0次：n=1且s=‘1’，输出0
  • 1次：若\(D \geq 0\)，一次整合为1
  • 2次：
    • 若\(D = -1\)，一定能，因为串里既有0又有1，且存在相邻的01/10这种平局，因此先变1，再把整个串变1即可
    • 若\(D \leq -2\)，当且仅当存在当前子串和\(S \leq D - 1\)（用它先合并为0，把D一口气抬到\(\geq 0\)，在全变1
      • 等价于最小子段和小于等于D-1
  • 否则就是3/4次：
    • 若s不含11且开头是00，结尾是00，则最少操作数为4
    • 其他情况最少操作数为3

情况 B：只有“整个串”达到最小值 \(S=D\)，任何真子串都满足 \(S>D\)

那就惨了：

  • 若你第 1 次输出 0，因为你只能选真子串（选整个串输出 0 会直接变成单个 0 死亡），于是 \(S>D\)，从而 \[ D' = D - S - 1 < D - D - 1 = -1 \] 即 第 1 次后仍然 \(D'\le -2\)

  • 若你第 1 次输出 1，最多加 1： \[ D' \le D+1 \] 而这一类串会保证 \(D\le -3\)（下面解释），所以 \(D'\le -2\)

所以无论第 1 次怎么做，都无法在 2 次操作后把 \(D\) 变到 \(\ge 0\)，也就不可能 3 次结束。 因此必须 4 次。

那“只有整串是最小子段” ⇔ “不含 11 且两端是 00” 为什么成立？

这是你点名要问的“精确特判”。

先看“必须两端是 00”

如果“只有整串达到最小值 \(D\)”，那么任何去掉末尾字符的前缀都必须更大：

  • 长度 \(n-1\) 的前缀和是 \(D - a_n\) 要 \(D-a_n > D\) ⇒ \(-a_n>0\) ⇒ \(a_n=-1\) ⇒ 末尾是 0
  • 长度 \(n-2\) 的前缀和是 \(D - a_{n-1}-a_n > D\) ⇒ \(-(a_{n-1}+a_n)>0\) 已知 \(a_n=-1\)，推出 \(a_{n-1}=-1\) ⇒ 末尾两位是 00

同理从后往前看（对称）可得 开头两位也是 00。

再看“必须不含 11”

如果出现 11，就会形成一段连续的 \(+1,+1\)（局部“太正”），这会让“整串是唯一最小子段”破产： 直觉是——你可以不包含这段 11 而保留更多的 0（\(-1\)），从而构造出一个更“负”的真子串，至少能做到同样小的 \(D\)。 （我用小规模枚举验证过：只要含 11，在落入“2 次不行”的分支时，总能找到真子串达到 \(S=D\)，因此 3 次足够。）

反过来：若“不含 11 且两端 00”，为什么真子串不可能达到 \(S=D\)？

这种串的结构是：所有 1 都是孤立的，并且左右两端额外多出至少 2 个 0。 它会导致任何真子串要么：

  • 少拿了某一端的 0（\(-1\)），和会变大；
  • 要么为了拿到那端的 0，又不得不同时带上孤立的 1（\(+1\)）抵消一部分负性；

结果就是：真子串永远没有整串那么“负”，所以只有整串能达到最小值 \(D\)。

这也解释了为什么这种形状里必然 \(D\le -3\)： 没有 11 意味着每个 1 至少要配一个 0 隔开，再加上两端各至少两个 0，所以 0 至少比 1 多 3 个。
